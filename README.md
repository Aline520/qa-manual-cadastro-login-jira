# 🧪 Projeto de QA Manual: Sistema de Cadastro e Login (Jira)

Projeto prático de **Garantia da Qualidade de Software (QA Manual)** focado na organização de tarefas em Kanban, elaboração de casos de teste (positivos e negativos), registro de defeitos (*Bug Report*) e acompanhamento do ciclo de vida de bugs no **Jira**.

> **Nota de transparência:** Cenário funcional simulado de Cadastro e Login com dados 100% fictícios para fins de estudo e portfólio.

---

## 🎯 Escopo Funcional
- **Cadastro:** Criação de nova conta de usuário (`QMCEL-1`).
- **Login:** Autenticação com e-mail e senha válidos (`QMCEL-2`).
- **Recuperação de Senha:** Solicitação de redefinição via e-mail (`QMCEL-3`).
- **Validações e Erros:** Tratamento e exibição de mensagens para dados inválidos (`QMCEL-4`).

---

## 📋 O Que Foi Documentado
- **Caso de Teste Positivo (`CT-001`):** Login com credenciais válidas (`QMCEL-2`).
- **Caso de Teste Negativo (`CT-002`):** Tentativa de login com senha incorreta (`QMCEL-4`).
- **Bug Report e Ciclo de Vida (`QMCEL-5`):** Registro de falha simulada ao inserir senha inválida, prioridade `High`, comentário de reteste e encerramento em `Feito`.

---

## 📸 Evidências do Projeto
- `01-espaco-jira-kanban` — Criação do espaço e quadro Kanban.
- `02-quadro-tarefas-organizadas` — Tarefas organizadas no quadro.
- `03-caso-teste-positivo-ct001` — Caso de teste positivo (`CT-001`).
- `04a-caso-teste-negativo-ct002` — Caso de teste negativo (`CT-002`).
- `04b-bug-report-qmcel5` — Bug Report (`QMCEL-5`) com prioridade `High`.
- `05-ciclo-de-vida-bug-feito` — Reteste registrado e bug fechado em `Feito`.
